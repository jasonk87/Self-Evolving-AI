## Reliability boundaries

- Chat history and model summaries are not authoritative connector data.
- Failed sync never refreshes provenance or turns unavailable into empty.
- No travel-time estimate without a directions source.
- No new external authority/cost granted by a background turn.
- Only completed, tested releases are marked delivered here.

## Foundation slice implementation

Implemented in the first release: v4 facts migration, atomic repository
and dependency invalidation, source sync/cursors, existing-sign-in Calendar
adapter, deterministic compute, facts/commitment tools, same-turn receipts,
open-item pointers, source viewer/API, correction incidents and mandatory

deferred scroll callbacks cannot target a different chat or override the reader.

of being silently dropped. Request-mocking browser tests block service workers
so requests cannot bypass their interceptors; a separate real-worker test checks
that private facts responses are not cached.
